# R.W.CC · 高校毕业致辞语料库

[访问语料库](https://ruwang01.github.io/rwcc-graduation-speech-corpus/)

本库收录 39 所高校 2017—2026 届的毕业典礼与相关学位授予仪式致辞。当前版本包含 336 篇主语料、1 篇补充材料，以及 83 条暂缺全文的登记。

在「致辞目录」按毕业届别、学校、致辞人和字数上限组合筛选。在「片段检索」按关键词或体裁编码查询，点击结果可定位到全文中的对应位置。暂缺全文的条目可跳转至学校官网。

## 文件与语料更新

- `index.html`、`app.js`、`styles.css` 是网页入口、检索逻辑和样式。
- `assets/` 包含项目木铎标识和仿宋库名矢量图。库名采用 [朱雀仿宋](https://github.com/TrionesType/zhuque/releases/tag/v0.212) 字形。
- `data/` 包含目录、致辞全文及对应的结构和来源索引。
- `build_data.py` 用于从解压后的研究数据包更新网页语料。运行 `python3 build_data.py /数据包所在文件夹`。

GitHub Pages 从 `main` 分支根目录发布。该网页也可以下载后离线打开。
